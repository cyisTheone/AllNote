# AC 含义

**AC = Accepted**，LeetCode、OJ 算法平台的术语

> ✅ **AC：通过，所有测试用例全部跑通，代码提交成功。**
> 
> 

相关常见状态：

|状态|全称|含义|
|---|---|---|
|AC|Accepted|全部用例通过，提交正确，可以得分|
|WA|Wrong Answer|答案错误，输出结果和预期不一样（比如 84 题把`‑1`漏掉就 WA）|
|TLE|Time Limit Exceeded|超时，代码逻辑对，但时间复杂度太高，跑不完大数据（暴力解法 O \(n²\) 就是 TLE）|
|RE|Runtime Error|运行时报错，数组越界、索引错误|
|MLE|Memory Limit Exceeded|超出内存限制|

结合 84 题：

- `单调递增栈解法（AC，O(n)）`：代表**这份代码提交 LeetCode 可以全部用例通过，时间复杂度 O \(n\)**

- 暴力解法标记没有写 AC，因为大数据会触发 **TLE 超时**，不能提交通过，只能用来理解思路。

### 面试口语

- “这题要写出 AC 代码” = 写出能线上提交通过的完整代码

- “暴力过不了，会 TLE，要优化到 O \(n\) 才能 AC”
