# 闭包
>
>定义

内层函数返回了外层函数的变量，当外层函数执行完时，将内层函数返回，内层函数仍然保持着外层函数的变量

```python
def outer(msg):
    # 自由变量
    text = msg
    # 内层函数
    def inner():
        print(text)
    return inner  # 返回函数对象，不是调用

func = outer("hello ollama")
func()   # 输出 hello ollama
```

1. `outer("hello ollama")`运行完毕，理论上局部变量`text`应该销毁
2. 但是`inner`捕获了`text`，形成闭包，变量被保留
3. 后续调用`func()`依然能访问 text


# 装饰器
在原有函数的基础上增加新的功能，但是不改变原有函数的功能

```python
# 装饰器函数
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        # 执行原始函数
        res = func(*args, **kwargs)
        print(f"耗时：{time.time() - start:.2f}s")
        return res
    return wrapper

def test():
    sum(range(100000))

# 手动包装
test = timer(test)
test()
```

`timer`接收函数，返回 wrapper 闭包；wrapper 在原函数前后增加逻辑。
> 痛点：`test = timer(test)` 写起来啰嗦

# 语法糖

**语法糖 = 等价简洁写法，底层逻辑完全不变，只是方便人阅读书写**
装饰器的 `@` 就是最经典的语法糖。

把上面代码改成 @语法糖形式：

```python
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        res = func(*args, **kwargs)
        print(f"耗时：{time.time() - start:.2f}s")
        return res
    return wrapper

# @timer 等价于 test = timer(test)
@timer
def test():
    sum(range(100000))

test()
```

✅ `@timer` 仅仅是简写，**底层和 `test = timer(test)`一模一样**。
> 拓展认知：python 很多都是语法糖
> `a += 1`、列表推导式、`with`语句、`async/await` 全部属于语法糖。
